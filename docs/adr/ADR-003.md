## Context

Letters arrive as PDF with a text layer or as plain text; readability must be visible.

## Options

- **A** – Text extraction in code (PDF text layer) plus agent A1.
- **B** – Azure Document Intelligence with OCR.
- **C** – A multimodal model reads PDF images.

## Decision

Proposal **A**: no additional paid resource; the synthetic PDFs have a text layer. Files that cannot be
read get the status `NICHT_LESBAR` (unreadable) and a visible task. B only as roadmap (it would need
approval as a paid service).

## Consequences

Every extracted fact needs a verbatim quote that the code finds again in the source text; otherwise it
is marked as "unsupported".

## Implementation in this repository (not part of the concept text)

- Deterministic extraction (identifiers, dates, places, references, event terms) runs in
  `src/pms/rules/extract.py` with the Python standard library; each value keeps its verbatim quote,
  character span and line number.
- PDF text layers are read with the optional package `pypdf` (included in the Azure image). If it is
  missing in the offline mode, a PDF upload becomes visibly unreadable (`NICHT_LESBAR` plus a task); it
  is never dropped. The text versions of all letters (`data/synthetic/letters/*.txt`) work without it.
